# Zəka Döyüşü (Битва Разумов)

Мультиплеерная браузерная стратегия-викторина на гексагональной карте.
Node.js (Express + Socket.io) на сервере, чистый JS + HTML5 Canvas в браузере.

## Запуск

```bash
npm install
npm start          # http://localhost:3000  (порт можно задать через PORT)
npm test           # юнит-тесты правил, карты и скрипта удаления фона
```

- **Одному:** введите имя и нажмите «🤖 Botla oyna». Игра сразу начнётся против бота среднего уровня.
- **С друзьями:** все открывают **одну и ту же ссылку** (например, адрес игры на Render) и вводят одинаковый код комнаты.
  Проще всего нажать в лобби «🔗 Dəvət linki» и отправить ссылку друзьям: она сразу подставит код комнаты.
  Открытые комнаты сервера видны на экране входа («Açıq otaqlar»).
  Создатель комнаты может добавить ботов («+ Bot əlavə et», уровни Asan / Orta / Çətin) и нажимает «Oyunu başlat»,
  когда в комнате от 2 до 8 участников.
  Если у кого-то на секунду пропал интернет, игра сама вернёт его в комнату.
- Звук включается и выключается кнопкой 🔊 в панели сверху.

## Правила

- Карта из гексов с дырами (узкие проходы), около 25 клеток на игрока: двое — 50 клеток, четверо — 100, восьмеро — 200.
  Партия идёт примерно 10–15 минут. Сложность клетки 1–5: чем темнее клетка, тем сложнее вопрос (точки внизу гекса).
- У каждого игрока Ратуша, 6 клеток вокруг неё и один Рыцарь. Цвета: синий, красный, зелёный, жёлтый.
- Атаковать можно только клетку, **соседнюю с вашей территорией** (она обведена пунктиром).
  Рыцарь идёт к ней по своим клеткам, **1 секунда на клетку**. Если клетку на пути захватили, рыцарь останавливается.
- У каждой клетки есть категория вопросов, её иконка видна на карте (🌍 география, ⚽ спорт, 🚀 космос…).
  Всего 12 категорий с общемировыми вопросами; создатель комнаты выбирает в лобби, какие из них участвуют.
- По прибытии появляется вопрос на азербайджанском и 4 варианта ответа. Таймер от 40 с (сложность 1) до 30 с (сложность 5).
  Повторы вопросов редки: пока есть новые, уже звучавший вопрос выпадает с вероятностью около 7%.
  - **Верно:** клетка ваша, а вопрос на ней навсегда меняется (анти-фарм).
  - **Неверно или время вышло:** правильный ответ не показывается, клетка блокируется **на 1 минуту только для вас**,
    вопрос на ней остаётся прежним, рыцарь возвращается на клетку, с которой пришёл.
- Пока на клетке кто-то отвечает, она занята для остальных, и над ней виден таймер.
- **Дуэль:** если два рыцаря идут к одной клетке, первый ждёт второго до 10 с. Оба отвечают на один и тот же вопрос:
  если оба ответили верно, следует новый вопрос; кто ошибся, тот проиграл и возвращается в Ратушу, а клетку получает другой.
  Если ошиблись оба, проигрывают оба. Если второй не успел за 10 с, первый отвечает один, а второй останавливается.
- **Ресурсы:** каждая клетка с золотом или деревом приносит владельцу +1 раз в 5 с.
- **Ратуша:** атаковать её всегда сложнее, чем обычную клетку.
  - Ур.1: 1 вопрос сложности 4.
  - Ур.2 (50 золота + 50 дерева): 2 вопроса подряд сложности 5, по 20 с на каждый.
  - Ур.3 (120 + 120): 3 вопроса подряд сложности 5, по 15 с на каждый.
- **Гибель рыцаря:** если враг захватил клетку, на которой стоит ваш рыцарь, рыцарь погибает и через 10 с возвращается в Ратушу.
  Так защитника можно убрать с пути к его Ратуше.
- **Режимы** (выбирает создатель комнаты):
  - «Paytaxtları tut»: побеждает тот, кто захватил все чужие Ратуши.
  - «Ərazi»: игра заканчивается, когда не осталось пустых клеток или создатель комнаты нажал «Oyunu bitir».
    Побеждает тот, у кого больше клеток (при равенстве — у кого больше ресурсов).
- **Захват Ратуши** работает в обоих режимах: захватчик забирает всю территорию и ресурсы её владельца, а проигравший становится наблюдателем.
  Если остался один игрок, он побеждает в любом режиме. Таймера матча нет.
- Захваченная столица остаётся на карте серыми руинами.
- Если игрок обновил страницу или потерял связь, он возвращается на своё место. В лобби место держится 30 с, в игре — 60 с.
- Боты улучшают Ратушу не сразу: не раньше нескольких минут после начала (зависит от уровня бота) и только с запасом ресурсов.
- **Боты** играют по тем же правилам, что и люди: ходят, отвечают (с вероятностью ошибки по уровню и сложности клетки),
  участвуют в дуэлях и улучшают Ратушу.

Все числа баланса собраны в `server/config.js`.

## Структура

| Путь | Что внутри |
|---|---|
| `server/Game.js` | Вся логика матча. Сервер авторитетный: правильный ответ никогда не уходит клиенту |
| `server/mapgen.js` | Генерация карты: дыры с проверкой связности, сложность, ресурсы, честная расстановка баз |
| `server/questions.js`, `data/categories.json`, `data/questions/*.json` | Категории и база вопросов: ~920 вопросов, написанных вручную, в 12 категориях |
| `server/generators.js`, `data/tables/*.json` | ~640 вопросов, собранных из таблиц (столицы и материки ~120 стран, химические элементы, устный счёт); в игре это не больше ~30% вопросов |
| `server/index.js` | Express + Socket.io, лобби комнат, боты в комнате, переподключение, `/healthz` |
| `server/Bot.js` | Компьютерный соперник |
| `shared/hex.js` | Гекс-математика (axial, pointy-top), общая для сервера и браузера |
| `public/js/game.js` | Рендер Canvas: слои, камера (перетаскивание мышью, колесо для зума), рыцари с плавным движением |
| `public/js/assets.js` | Загрузка спрайтов и их тонировка под цвет игрока |
| `public/js/ui.js`, `main.js` | Лобби, HUD, окно вопроса, тексты интерфейса |
| `public/js/sound.js` | Звуки, синтезированные через WebAudio (файлов нет) |
| `render.yaml` | Настройки хостинга на Render |
| `tools/remove-bg.js` | Удаление фона у картинок |

## Онлайн на Render.com (бесплатно)

1. Зайдите на https://render.com и нажмите **Get Started**, затем войдите через **GitHub**.
2. Если Render попросит доступ к репозиториям, разрешите доступ к `Fareonx/Trivia`.
3. В панели Render нажмите **New → Blueprint** и выберите репозиторий `Fareonx/Trivia`.
4. Render найдёт файл `render.yaml` и покажет сервис `zeka-doyushu`. Нажмите **Apply** (или **Deploy Blueprint**).
5. Через 2–5 минут сборка закончится. Ссылка на игру вида `https://zeka-doyushu.onrender.com` появится
   вверху страницы сервиса. Её можно отправлять друзьям.

Полезно знать:
- Render берёт код из ветки **`main`**. Каждое слияние pull request в `main` автоматически обновляет игру.
- Бесплатный сервер **засыпает**, если 15 минут никто не играет. Первое открытие после этого занимает около минуты,
  дальше всё работает быстро. Активные комнаты при засыпании пропадают.
- Чтобы на GitHub по умолчанию открывалась `main`: Settings → General → Default branch → выбрать `main` → Update.

## Свои картинки (Рыцарь, Ратуша, ресурсы)

1. Уберите фон:
   ```bash
   node tools/remove-bg.js knight-raw.png public/assets/knight.png --trim
   ```
   Скрипт берёт цвета фона с краёв картинки, поэтому справляется и с «нарисованной шахматкой» из AI-генераторов.
   Если вместе с фоном съедаются светлые края спрайта, уменьшите `--tolerance` (по умолчанию 32).
2. Укажите новый файл в `ASSET_FILES` в `public/js/assets.js`.
3. **Части, которые должны быть цвета команды** (флаг, щит, крыша), рисуйте **синим**. Игра один раз при загрузке
   перекрашивает только синие оттенки в цвет каждого игрока, а серая броня, дерево и золото остаются как есть.
   Перекраска делается заранее, а не через `ctx.filter` в каждом кадре, поэтому одинаково работает во всех браузерах.

## Добавление вопросов

Допишите вопрос в файл нужной категории в `data/questions/` (список категорий — в `data/categories.json`):

```json
{ "id": "space-29", "category": "space", "difficulty": 3, "text": "Sual?", "correct": "Düz cavab", "wrong": ["Səhv 1", "Səhv 2", "Səhv 3"] }
```

Сервер сам перемешивает варианты ответа и подбирает вопрос по категории и сложности клетки.
Новую категорию можно добавить, создав файл в `data/questions/` и строку в `data/categories.json`.
`npm test` проверяет, что у каждого вопроса 4 разных варианта и что в каждой категории есть вопросы всех 5 уровней сложности.
