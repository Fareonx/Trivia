# Zəka Döyüşü (Битва Разумов)

Мультиплеерная браузерная стратегия-викторина на гексагональной карте.
Node.js (Express + Socket.io) на сервере, чистый JS + HTML5 Canvas в браузере.

## Запуск

```bash
npm install
npm start          # http://localhost:3000  (порт можно задать через PORT)
npm test           # юнит-тесты правил, карты и скрипта удаления фона
```

Откройте игру в двух вкладках (или на двух устройствах в одной сети), введите имя и одинаковый код комнаты.
Создатель комнаты нажимает «Oyunu başlat», когда в ней 2–4 игрока.

## Правила

- Карта из гексов с дырами (узкие проходы). Сложность клетки 1–5: чем темнее клетка, тем сложнее вопрос (точки внизу гекса).
- У каждого игрока Ратуша, 6 клеток вокруг неё и один Рыцарь. Цвета: синий, красный, зелёный, жёлтый.
- Атаковать можно только клетку, **соседнюю с вашей территорией** (она обведена пунктиром).
  Рыцарь идёт к ней по своим клеткам, **2 секунды на клетку**. Если клетку на пути захватили, рыцарь останавливается.
- По прибытии появляется вопрос на азербайджанском и 4 варианта ответа. Таймер от 40 с (сложность 1) до 30 с (сложность 5).
  - **Верно:** клетка ваша, а вопрос на ней навсегда меняется (анти-фарм).
  - **Неверно или время вышло:** правильный ответ не показывается, клетка блокируется **на 1 минуту только для вас**,
    вопрос на ней остаётся прежним, рыцарь возвращается на клетку, с которой пришёл.
- Пока на клетке кто-то отвечает, она занята для остальных, и над ней виден таймер.
- **Дуэль:** если два рыцаря идут к одной клетке, первый ждёт второго до 10 с. Оба отвечают на один и тот же вопрос:
  если оба ответили верно, следует новый вопрос; кто ошибся, тот проиграл и возвращается в Ратушу, а клетку получает другой.
  Если ошиблись оба, проигрывают оба. Если второй не успел за 10 с, первый отвечает один, а второй останавливается.
- **Ресурсы:** каждая клетка с золотом или деревом приносит владельцу +1 раз в 5 с.
- **Ратуша:** на ур.2 (50 золота + 50 дерева) у атакующего только 20 с на ответ; на ур.3 (120 + 120) нужно ответить верно на 2 вопроса подряд.
- **Победа:** тот, кто захватил чужую Ратушу, забирает всю территорию и ресурсы её владельца, а проигравший становится наблюдателем.
  Побеждает последний оставшийся игрок. Таймера матча нет.
- Если игрок обновил страницу, он возвращается на своё место. Если он отключился больше чем на 60 с, он выбывает.

Все числа баланса собраны в `server/config.js`.

## Структура

| Путь | Что внутри |
|---|---|
| `server/Game.js` | Вся логика матча. Сервер авторитетный: правильный ответ никогда не уходит клиенту |
| `server/mapgen.js` | Генерация карты: дыры с проверкой связности, сложность, ресурсы, честная расстановка баз |
| `server/questions.js`, `data/questions.json` | База вопросов (`difficulty`, `correct`, `wrong`) |
| `server/index.js` | Express + Socket.io, лобби комнат, переподключение |
| `shared/hex.js` | Гекс-математика (axial, pointy-top), общая для сервера и браузера |
| `public/js/game.js` | Рендер Canvas: слои, камера (перетаскивание мышью, колесо для зума), рыцари с плавным движением |
| `public/js/assets.js` | Загрузка спрайтов и их тонировка под цвет игрока |
| `public/js/ui.js`, `main.js` | Лобби, HUD, окно вопроса, тексты интерфейса |
| `tools/remove-bg.js` | Удаление фона у картинок |

## Свои картинки (Рыцарь, Ратуша, ресурсы)

1. Уберите фон:
   ```bash
   node tools/remove-bg.js knight-raw.png public/assets/knight.png --trim
   ```
   Скрипт берёт цвета фона с краёв картинки, поэтому справляется и с «нарисованной шахматкой» из AI-генераторов.
   Если вместе с фоном съедаются светлые края спрайта, уменьшите `--tolerance` (по умолчанию 32).
2. Укажите новый файл в `ASSET_FILES` в `public/js/assets.js`.
3. **Части, которые должны быть цвета команды** (флаг, щит, крыша), рисуйте **синим**. Игра один раз при загрузке
   перекрашивает только синие оттенки в цвет каждого игрока, а серая броня, дерево и золото остаются как есть.
   Перекраска делается заранее, а не через `ctx.filter` в каждом кадре, поэтому одинаково работает во всех браузерах.

## Добавление вопросов

Допишите вопрос в `data/questions.json`:

```json
{ "id": 69, "difficulty": 3, "text": "Sual?", "correct": "Düz cavab", "wrong": ["Səhv 1", "Səhv 2", "Səhv 3"] }
```

Сервер сам перемешивает варианты ответа и подбирает вопрос по сложности клетки.
